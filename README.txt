RAJKUMAR BHANDARI — RESEARCH WEBSITE

FOLDER STRUCTURE
----------------
index.html          Home page
about.html          About / education
research.html       Research areas
projects.html       Projects
publications.html   Publications
cv.html             CV page
contact.html        Contact page
css/style.css       Website styling
js/script.js        JavaScript
images/             Put photographs and research images here
documents/          Put CV.pdf and other documents here

HOW TO UPDATE
-------------
1. Open the HTML files in a text editor such as VS Code.
2. Replace text inside [square brackets].
3. Replace YOUR_EMAIL@example.com with your email.
4. Put your photograph inside images/ and update the image section.
5. Put your CV at documents/CV.pdf.
6. Replace publication placeholders with your actual papers.

HOW TO VIEW
-----------
Double-click index.html to open the website in a browser.

FOR ONLINE HOSTING
------------------
You can upload this folder to GitHub and use GitHub Pages to make it publicly accessible.
